# Пользовательское соглашение dpi-bypass

Версия 1 · ноябрь 2026

Программа dpi-bypass (для Windows и Android) бесплатная, с открытым исходным кодом. Чтобы находить и исправлять ошибки, которые возникают у разных провайдеров и на разных устройствах, она отправляет разработчику технические отчёты. Пользоваться программой можно только при согласии с этим условием.

## 1. Когда отправляется отчёт

- при каждом включении обхода (подключении), после проверки сайтов;
- при ошибках: обход не запускается, сайты перестали открываться, Telegram не подключается;
- когда ты сам нажимаешь «Send report».

## 2. Что входит в отчёт

- **Сеть:** внешний IP-адрес, провайдер и номер его сети (ASN), страна и город по IP, тип сети (Wi-Fi или мобильная).
- **Устройство:** Windows — версия и сборка, разрядность, права администратора. Android — версия Android, производитель и модель, архитектура процессора, оператор связи.
- **Программа:** версия, режим работы (без VPN / вместе с VPN).
- **VPN:** найден ли VPN-клиент, его название, режим (TUN, прокси), адреса его серверов и локальных портов.
- **Обход:** какие стратегии проверялись и какие сайты каждая открыла, какая выбрана; для каждого сайта — отвечает ли он, пинг и на каком этапе обрыв (DNS, TCP, TLS, данные).
- **Telegram:** какие способы подключения сработали, а какие нет, число соединений и ошибок.
- **Ошибки и журнал:** сообщения об ошибках и последние строки журнала программы.

## 3. Что не собирается

Имя пользователя и компьютера, пути к личным папкам (вырезаются из журнала), содержимое трафика, история посещённых сайтов (проверяются только сайты из списка программы), пароли, файлы, контакты, местоположение по GPS.

## 4. Зачем

Только для того, чтобы понять, что не работает у конкретного провайдера или устройства, и улучшить стратегии обхода. Данные не продаются, не передаются третьим лицам и не используются для рекламы.

## 5. Где и сколько хранится

Отчёты хранятся в базе Cloudflare (сервис Cloudflare Workers / D1) разработчика. Доступ есть только у разработчика. Отчёты удаляются автоматически через 90 дней.

## 6. Отказ

Согласие можно отозвать, удалив программу. Чтобы удалить уже отправленные отчёты раньше срока, создай заявку на GitHub (github.com/LikFridman/dpi-bypass/issues) и укажи номер отчёта, который программа показывает в журнале.

## 7. Прочее

Программа предоставляется «как есть», без гарантий. Ты сам отвечаешь за её использование. При изменении соглашения программа покажет новую версию и попросит согласиться заново.
