На Android одновременно может работать только один VPN. Пока обход включён, он заменяет другой VPN (например, Happ). Сайты, заблокированные по IP, идут через встроенный VPN (вкладка VPN).

VPN

—
VPN нужен там, где обход не помогает: сервис заблокирован по IP. Такие сервисы идут через VPN сами, остальные - через обход, на полной скорости. Для любого сервиса способ можно выбрать вручную: Sites → нажми на сервис.

Какие сервисы нужны?

Подбор и проверки - только по отмеченным, поэтому быстрее. Остальные идут напрямую, без обхода. Изменить можно в любой момент: Sites → Choose.
