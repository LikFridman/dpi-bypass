На Android одновременно может работать только один VPN. Пока обход включён, он заменяет другой VPN (например, Happ). Сайты, заблокированные по IP, без настоящего VPN не откроются.

Telegram

Telegram proxy

Starts with the bypass
Нажми «Connect Telegram» один раз и подтверди в Telegram. Дальше он сам ходит через обход, пока обход включён. Звонки через прокси Telegram не поддерживает.

Backup proxies

Если WebSocket к Telegram не проходит, трафик пойдёт через твой прокси: ссылки tg://proxy (в том числе FakeTLS-секреты ee…) или socks5://адрес:порт.

Cloudflare Worker

Нужен, если у провайдера заблокированы IP-адреса Telegram. Инструкция — в README на GitHub.
