Telegram Desktop proxy

Starts with the bypass

Routes

  1. WebSocket к web.telegram.org — через обход DPI
  2. Свой Cloudflare Worker — если IP Telegram заблокированы
  3. Твой запасной прокси (MTProto или SOCKS5)
  4. Напрямую к серверам Telegram
  5. Через VPN (режим «With VPN»)

Public proxies

Источники: публичные списки MTProto на GitHub; каждый прокси проверяется запросом req_pq к DC2.

Backup proxies

Если ничего выше не проходит, Telegram пойдёт через твой прокси. Подходят ссылки tg://proxy (в том числе FakeTLS-секреты ee…) и socks5://адрес:порт.

Windows Defender

Защитник иногда считает winws и драйвер WinDivert опасными: они перехватывают сетевые пакеты. Это ложное срабатывание. Чтобы файлы не удалялись, добавь папку программы в исключения.
  1. Скопируй путь кнопкой ниже
  2. «Защита от вирусов и угроз» → «Управление настройками»
  3. «Исключения» → «Добавить исключение» → «Папка» → вставь путь
